Transtipage (cast)

Java Core

Explication de la notion

Le transtypage (ou cast) est un mécanisme qui permet de transformer une donnée d'un type en une donnée d'un autre type. Il y a deux types de conversion en Java : 
- la conversion implicite (effectuée automatiquement par le compilateur),
- la conversion explicite (effectuée par le développeur selon le besoin).
Le transtypage (ou cast) est un mécanisme qui permet de transformer une donnée d'un type en une donnée d'un autre type. Il y a deux types de conversion en Java : 
- la conversion implicite (effectuée automatiquement par le compilateur),
- la conversion explicite (effectuée par le développeur selon le besoin).
Example.java 
public class Main {
    public static void main(String[] args) {
        //Cast implicite
        int a = 9;
        double b = a; // la valeur de a est castée implicitement en double
        System.out.println(b); // 9.0

        //Cast explicite obligatoire
        float c1 = 5.5; // Erreur de compilation car 5.5 est de type double par défaut
        float c2 = (float) 5.5; // Déclaration correcte
        float c3 = 5.5f; // Déclaration correcte

        //Cast explicite avec risque perte valeur
        float d = 10.5f;
        int e = (int) d; // on perd la partie flottante
        System.out.println(e); // 10
    }
}
