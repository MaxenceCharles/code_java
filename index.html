Classes Wrapper

Java Core

Explication de la notion

Comme les types primitifs ne sont pas des classes et ne portent pas de méthodes, l’API standard de Java fournit des classes qui permettent d’envelopper la valeur d’un type primitif : on parle de classes enveloppantes (ou de Wrapper Classes en anglais) ou wrapper.
Les wrapper sont des classes qui portent des méthodes permettant d'agir sur des primitifs.
Example.java 
public class Main {
    public static void main(String[] args) {
        //Exemple 1 :
        char c = '1';
        Character cObj = Character.valueOf(c); // Wrapper contenant '1'
        
        Integer resultatObj = Integer.valueOf(cObj.toString()); // Wrapper contenant 1
        int resultat = resultatObj.intValue(); // conversion d'Integer en int

        //Exemple 2 :
        char c = '1';
        Character cObj = c; // auto boxing
        int resultat = Integer.valueOf(cObj.toString()); // auto unboxing

        //Exemple 3 : utilisation d'une méthode utilitaire du Wrapper
        char c = '1';
        int resultat = Character.getNumericValue(c);
    }
}
